# Module 1 Adapter - Tests

This directory contains test files for the Module 1 Adapter.

## Structure

- `unit/` - Unit tests for individual components
  - `test_java_events.py` - Java event extraction test
  - `test_langs.py` - Multi-language test script

## Running Tests

```bash
# Run individual test
python tests/unit/test_java_events.py

# Run all language tests
python tests/unit/test_langs.py
```

## Integration Tests

See `examples/multi_lang/` for comprehensive test files for each language.
